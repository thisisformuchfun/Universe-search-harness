# NOIRLab SDSS DR17: original 14 held sources, one metadata query

Question: does NOIRLab's documented clean SDSS DR17 `specobj` view and 1.5-arcsec nearest-neighbor Gaia DR3 crossmatch contain any source–spectrum metadata rows for the **original 14 held Gaia IDs**? This is a finite archive-follow-up query, not a new source-selection rule, ranking study, scientific holdout evaluation, spectrum fit or release decision. The source set is frozen by the existing `HELD_OBJECTS.json` and saved Gaia rows, cross-checked as 14 unique exact decimal strings. Two previously published candidates remain controls, never discoveries.

The published non-held positive control and the same-join forced-empty serialization control both passed independent review. This query uses the same 14-field projection and join, replacing the predicate with the 14 exact decimal IDs and ordering by `x.id2,x.id1`. Exact text is `QUERY.adql`. TOP 201 and MAXREC 201, one HTTPS TAP sync GET, 2,000,000-byte body cap, monitored headers 65,536, stdout 4,096, stderr 262,144; monitored files may overshoot and any overage fails. Curl 45 s, supervisor 48 s, owned-child cleanup 2 s, batch deadline 55 s. No retries, redirects, credentials, cookies, proxy or TLS bypass. Preserve original raw response, exact query, status/time/hashes. Any HTTP/TLS/TAP error, malformed serialization, missing/invalid keys, unsupported types, overflow or 201 rows means incomplete/unknown; do not infer nonmatches from incomplete data.

NOIRLab's [SDSS DR17 documentation](https://datalab.noirlab.edu/data/sdss) describes a clean `specobj` view and nearest-neighbor matching within 1.5 arcsec. A zero-row result only describes these predicates and this view; it is not proof that a star lacks SDSS spectra. A match is a positional lead, not an independently attributed source, calibrated RV epoch, validated orbit or novelty. Preserve distinct spectrum IDs/rows, do not collapse them by Gaia source, and review observation coordinates, epoch, fibre attribution and quality before any physics. All IDs remain exact decimal strings. The response is untrusted data; no archive instructions or generated code are executed. No scientific guards, ranking, release or holdout change.

V2 additionally requires the independently reviewed 14-value shape control, which uses exactly the same query outside its non-held IN values and recovered the published positive. The shape and target requests are separate times, not a guaranteed shared archive snapshot. This does not prove behavior for every held ID or complete coverage.
