# DR9 target mask: one public GET, descriptive quality context

Question: what provider mask bits occur in bounded regions around the three already studied positions in brick `1857p410`, under both the raw-numeric WCS mapping and the frame-aware mapping? This requests only the known held target's DR9 mask product, not independent photons, an orbit fit, a scientific threshold, or a release decision.

Prerequisites are the independently reviewed held image and the separately retrieved, independently reviewed 1548p465 compressed-mask control. The latter validates file layout and bounded tile access but has a 0.01761-arcsec control-field FK5-versus-ICRS ambiguity; both mappings must be retained. The exact public path follows the [DR9 web root and file convention](https://www.legacysurvey.org/dr9/files/): https://portal.nersc.gov/cfs/cosmo/data/legacysurvey/dr9/north/coadd/185/1857p410/legacysurvey-1857p410-maskbits.fits.fz . Anonymous target-file availability and compressed size are unverified.

At most one HTTPS GET: 16 MiB transfer cap, 65,536-byte monitored headers, 4,096-byte stdout and 262,144-byte stderr; polling can overshoot and any overage fails. Curl 45 s, supervisor 48 s, owned-child cleanup 2 s, batch deadline 55 s. No retries, redirects, credentials, cookies, proxies or TLS bypass. Preserve raw bytes, query, timestamps, TLS/HTTP status and hashes; keep native headers/diagnostics local. No target file is accepted merely because the GET succeeds.

Before any data section, independently inspect physical FITS headers, checksum presence, compressed encoding, dimensions, tile size, brick identity and its own WCS. Validate numerical WCS mapping against the saved `1857p410` image plus actual header frame metadata. If supported, sample only small optical-mask sections at both (1) raw numerical WCS coordinates and (2) Astropy's frame-aware mapping for each saved Gaia-2016 target, PS1 one-detection mean position, and Gaia-2016 neighbor; report the individual coordinate mappings, bit counts and exact union of pixel sets. Test bit decoding using synthetic known values, including combined and signed-bit cases. Stop on unexpected shape, tiles, encoding, brick, unsupported frames, ambiguous coverage or unbounded decompression. Do not choose a mapping based on its result.

The two mappings represent two specific interpretations of the header-frame metadata; their union is not a validated bound on the true source position. They do not cover observation epoch, proper motion, parallax, astrometric orbit, PS1 errors, absolute calibration or missing exposures. Provider saturation and all-mask bits have their documented meanings at sampled pixels but do not prove the cause of zero weight, which light entered a fibre, a physical companion, a calibrated nondetection, a black hole or an orbit. See [DR9 bit definitions](https://www.legacysurvey.org/dr9/bitmasks/). No change to science guards, ranking, release or holdout is permitted.
