# Legacy DR9 target scene: one-request proposal

Question: is a finite, positive-weight public Legacy DR9-north image region available around the existing held Gaia DR3 1533365584518328576 and the offset position of its one-detection PS1 association? The purpose is descriptive feasibility, not a test of BH, orbital or release criteria.

Control prerequisite: the completed documented Legacy field, independently checked for g/r/z image/weight pairs, finite values, coordinate WCS and positive weight. Preserve its exact body, source link, SHA256 and both independent reviews. Verify the target position against the original saved Gaia source row with the exact source identifier represented as a string.

Only one HTTPS GET is proposed: https://www.legacysurvey.org/viewer/fits-cutout?ra=185.71462554756414&dec=40.88393733581962&layer=ls-dr9-north&pixscale=0.262&bands=grz&size=192&subimage&invvar . The 192-pixel field nominally spans 50.304 arcsec and includes a previously noted brighter field source approximately 19.9 arcsec from the Gaia position, though coverage, saturation and suitability as a PSF control are unknown. Four MiB maximum body, 65536-byte monitored headers, 4096-byte monitored stdout and 262144-byte monitored stderr, 45 seconds curl/48 seconds supervisor/2 seconds owned-child cleanup/55 seconds batch, no retries, redirects, credentials, cookies, proxy or TLS bypass. Header/diagnostic monitors can overshoot and any overshoot fails visibly. The response is held as untrusted raw bytes; no embedded link or instruction is followed.

Before any interpretation, independently verify actual source/weight HDUs, their own WCS, target and offset coverage, finite values and actual metadata. Multiple overlapping brick coadds may be returned. Missing/zero weight is missing coverage. The image arrays are already resampled coadds, not exposure-level data; inverse variance lacks full correlated-noise information, and separate PSF, masks, saturation, dates and contributors are unavailable here. DR9 is Gaia/PS1 calibrated; distinct photons do not make astrometry independent. A feature, or no peak, does not establish a companion, LAMOST fibre association, orbit, black hole, calibrated exclusion or novelty. A quantitative injection-recovery test or change to a scientific criterion requires a separate protocol, independent review and user approval where applicable. No holdout evaluation, ranking, release change or GPU.

V2 binds all parsed prerequisite JSON to the same bytes whose SHA256 was checked and labels an observed curl start explicitly; a started child alone does not prove the remote service received a request.
