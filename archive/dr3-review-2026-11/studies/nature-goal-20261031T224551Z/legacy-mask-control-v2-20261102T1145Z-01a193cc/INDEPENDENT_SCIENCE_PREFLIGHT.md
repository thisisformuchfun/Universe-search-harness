On 2026-11-02 UTC `/root/ps1_science_review` identified the documented DR9 north maskbits product as a potentially useful quality-context follow-up and proposed the already imaged brick 1548p465 as the provider-format/WCS control. The [DR9 file documentation](https://www.legacysurvey.org/dr9/files/) describes the north archive, filename convention, 3600x3600 brick grids and optical mask in HDU1; the actual file, compression, size and availability remain unverified. [DR9 bit definitions](https://www.legacysurvey.org/dr9/bitmasks/) describe saturation and ALLMASK bits in each band.

Before interpreting any mask, check its actual FITS layout, dimensions and WCS against the saved control image; verify checksums if present, and use bounded sections for compressed data. Synthetic known-bit tests are necessary because a nonzero positive control flag has not been established. A zero bit is not a proof of clean pixels, and a set bit does not by itself determine the cause of zero weight, the exposure contributing photons, the PSF, an orbit or source attribution. The later 1857p410 target mask requires a separately reviewed continuation; the current request is control-only. No scientific criterion, ranking, release or holdout change is proposed.
